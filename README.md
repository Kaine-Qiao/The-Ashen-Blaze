# The-Ashen-Blaze
盛昭封与镇妖系列故事的三国背景设定
　　昔年妖族大举进攻人族，盛朝的修士与凡俗将士浴血奋战，最终以巨大的牺牲驱逐了妖族至南疆。
    但妖族并未死心，时不时发动一次妖潮来犯，盛朝建立镇妖战时体系，举全国之力，结合人族先辈留下的残破长城，修筑镇妖长城以及镇妖关。
    最后伴随当时领导的妖王被斩杀，妖族也遭到重创。它们失去了统一的大规模的军队，分裂成无数零散部族。百余年里，再没有出现过能够攻垮长城的大规模入侵。小规模妖祟、零星妖物出没仍时有发生，但都只是地方祸患，不再是足以灭族的浩劫
（镇妖长城这条防线，自人妖大战结束起，就由两套体系共同维持：
 凡俗体系：王朝的边军，负责城墙、关隘、屯堡、后勤、巡逻
修士体系：各大修行宗门联盟，在大战时修士负责斩杀实力强大的妖族，如妖将、妖帅、妖王，击溃妖族高端战力；战后宗门仍会继续在长城沿线设立驿馆、监察点，定期巡查南疆区域。）
    岁月流转，烽烟沉寂，一晃一百五十余年太平岁月悄然流逝。 
　　盛朝依托镇妖长城的安稳格局休养生息，天下户口滋繁、田亩开垦，百年盛世蔚然成型，可长久无灭国大患，人族心中刻入骨髓的危机感，终究缓缓消磨殆尽。
    世人大多认为：有宗门修士帮忙，且妖族残部早已不成气候，绝无卷土重来、倾覆人族的可能。地方上的零星妖祟作乱根本无需举国紧绷战时之弦，仍沿用百年的举国战时边防体系是不合时宜的——
    当年为对抗妖族定下的整套国策——全国统筹征粮、抽调民夫、重赋七成供养长城大军、各地征发徭役修缮关隘、地方资源优先供给边防，本是临危救亡的权宜之策。
如今大妖之患平息许多载，这套战时架构却没有随之改制，依旧原样运行。国家财政优先倾斜南疆长城防线，各地郡县都要按战时定额输送粮草、物资与劳役，不因天下承平而减免。
　　这套僵化不变、沿用百年的战时旧制，便是盛朝一切崩坏、天下三分的根源——
    盛朝末代君主，并非昏暴亡国之君。
其早年勤政有为，修整边防、稳固社稷，确有守土安世之功，撑起了百年盛平格局。
可时至晚年，帝王心性日趋怯懦、保守、多疑。
    他亲身见过妖潮屠世之惨，根深蒂固畏惧妖族卷土重来。在他心中：妖患从未根除，只要南疆仍有妖气，人族便不能松懈，战时祖制绝不能废。
　　可与此同时，他又极度忌惮南疆边军权势过大、根深蒂固。百年战时体系滋养出的南疆边防重兵，手握天险、世袭戍边、兵权自治、威望盖世，让晚年帝王寝食难安。
    
    他惧妖，不敢彻底改制放松边防；
　　他惧军，不敢放任南疆三军强势壮大。
 
　　最终，在身边宠臣党羽的怂恿撺掇之下，末代帝王走上了最畸形、最致命的折中权术：
名义完整保留战时重赋旧制，依旧榨取天下万民供养边防框架，用以防备妖族复辟；
    暗地里默许一些权贵的贪污行为，逐年克扣南疆军饷、削减军备物资、裁撤戍边编制、回收边军自治权限，用以削弱兵权、稳固皇权。
    天下万民负重依旧，可本该用来守御人族的南疆边防力量，被朝廷日复一日掏空、削弱、制衡，朝野人心，自此彻底撕裂。
 
　　彼时朝堂之中，雍王爷为宗室贤王，身负大局远见。
　　他自幼熟读人妖血战史，深知先辈守土之艰，从不轻视妖族蛰伏的隐患，更明白镇妖长城是人族最后的底线。
　　但雍王也亲眼目睹天下生民疾苦：百五十年承平无大战，僵化战时旧制无休止压榨四方——西北贫瘠年年重输粮草徭役，百姓们不堪长期重赋，民间疲敝、国力凝滞、百业难兴。
    雍王认定：妖族隐患仍在，边防不可全废；但战时苛制必改、万民重压必解、畸形国策必除。
    旧帝的懦弱苟且，看似维稳，实则一边耗空民生、一边废弛边防，最终只会拖垮人族根基。
    雍王心怀天下，不愿见盛朝在内耗中自毁山河。他暗中积蓄力量，私养精锐义兵，联结朝堂清流臣子，隐忍数年、静待天时，只待拨乱反正、清君侧、破旧制、安万民、扶正盛朝山河。
 
    而承受最深伤害、最心寒彻骨的，便是南疆镇守万里长城的三大戍边精锐：镇妖军、封夷军、卫疆军————
 （封夷军：南疆野战主力，专司正面迎击妖潮、清缴大股妖众；
镇妖军：镇守镇妖关、南疆诸道雄隘，锁死妖物北上要道；
卫疆军：守备沿线屯堡、修缮长城工事、打理边防后勤、安定南疆边民。）
    三军世代戍边、血染荒疆，比世间任何人都清楚妖气未散、妖祸未熄。他们从不敢懈怠守御，始终紧绷人族最后一道防线，可换来的，却是朝廷经年累月的猜忌、克扣、削权、冷待。
　　忠骨浴血护世，反倒沦为皇权制衡的牺牲品；百战雄师守御边疆，反倒被朝堂视作尾大不掉的隐患。
    三军将士心寒透骨、群情激愤。
    朝廷无守土之心、无惜军之意、无顾民之念，只剩权术苟且、自毁藩篱。若再俯首听命，他日妖潮再起、长城虚废，整个人族必将万劫不复。
    三军诸将集体死谏大统帅，恳请自立安疆、保全防线。
    南疆三军最高统帅，本是世代戍边忠臣，一生守疆护民、从无割据异心。他不愿叛盛、不愿裂土、更无意称帝称王。
　　可望着麾下世代浴血的将士、万里残破的长城、依附防线存活的南疆万民，他深知——自己不立，则边防崩、南疆灭、人族危。
    万般无奈之下，他被三军将士众望所逼，舍弃盛朝官身，以南疆天险与三军基业立国，定国号为封。

　　另一边，饱受战时旧制百年重压的西北疆域，土地贫瘠、资源匮乏，却年年足额承担最重的战时粮赋、徭役、物资征调。
　　西北百姓未见灭国妖患，只见到代代无尽压榨。官民皆疲、怨气积世，最终全境举义，组建昭明军，向外攻伐，挣脱盛朝腐朽体制，后割据西北险地自立，定国号为昭。

　　而在这天下分裂、朝政溃烂之时，雍王也顺大势，举义兵、清奸佞、伐昏君，一战定京畿。
　　他诛杀末代帝王与乱政宠臣，以匡扶正统、重整制度、平衡边防与民生为己任，据东北故土延续盛朝天统，立国号依旧为盛。
  
　　自此，传承数百年的大一统盛朝彻底崩塌，天下三分：
　　东北盛国、南疆封国、西北昭国。
　　昔日共御妖祸、同心护世的人族山河，彻底分裂。 
　　人族外无灭世妖潮，却深陷无尽内耗；墙外妖族蛰伏瘴林、休养生息、静待人族元气耗尽。
    万里镇妖长城依旧横亘南疆，宗门仙士依旧岁岁巡荒镇邪、不涉凡俗王朝间的纷争，但在暗中谁又知道呢

　　墙内人间手足相残，墙外妖祸暗蓄锋芒。人族未亡于妖祸，先乱于承平积弊、僵制崩心。道玄五千载，烬烽乱世，自此开篇——
